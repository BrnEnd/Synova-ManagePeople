# Domain Docs

Antes de explorar uma área, leia o `CONTEXT.md` da raiz, quando existir, e os ADRs relevantes em `docs/adr/`.

Este é um repositório de contexto único. O glossário de domínio será mantido em `CONTEXT.md`; decisões técnicas duráveis serão registradas em `docs/adr/` quando necessárias.

Se esses arquivos ainda não existirem, prossiga sem mencioná-los. A skill de modelagem de domínio os cria apenas quando houver terminologia ou decisão consolidada a registrar.
