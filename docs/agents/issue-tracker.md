# Issue tracker: GitHub

Issues e especificações deste repositório vivem no GitHub Issues. Use a CLI `gh` para todas as operações.

## Convenções

- Criar issue: `gh issue create --title "..." --body "..."`.
- Ler issue: `gh issue view <número> --comments`.
- Listar issues: `gh issue list` com os filtros apropriados.
- Comentar, alterar rótulos ou fechar: use `gh issue comment`, `gh issue edit` e `gh issue close`.

O repositório é inferido pelo remoto Git configurado.

## Pull requests como superfície de triagem

**Não.** Pull requests externos não participam da triagem padrão.

## Publicação de especificações

Quando uma skill solicitar publicação no rastreador, crie uma GitHub Issue.
